### A Collection Of Online Resources

_Learn Java for FTC_, an ebook by (FTC Coach) Alan G. Smith: [https://raw.githubusercontent.com/alan412/LearnJavaForFTC/master/LearnJavaForFTC.pdf](https://raw.githubusercontent.com/alan412/LearnJavaForFTC/master/LearnJavaForFTC.pdf)

The software section, with tutorials,in _Game Manual Part 0_: [https://gm0.org/en/latest/docs/software/index.html](https://gm0.org/en/latest/docs/software/index.html)

This stuff is better commented than your own team's code: [https://github.com/FIRST-Tech-Challenge/FtcRobotController/tree/master/FtcRobotController/src/main/java/org/firstinspires/ftc/robotcontroller/external/samples](https://github.com/FIRST-Tech-Challenge/FtcRobotController/tree/master/FtcRobotController/src/main/java/org/firstinspires/ftc/robotcontroller/external/samples)
